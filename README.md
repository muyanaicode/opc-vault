# OPC Vault · 账套库

本地优先、端到端加密的**企业账套管理插件**，以 **DeepSeek Harness（DSH）插件**形式运行在 Harness Web UI 中。
所有公司主体与账套资料只保存在你自己的机器上，用 AES‑256‑GCM 加密，永不离开本地。

> 面向「一人公司 / OPC（One Person Company）」、小微企业主与代账机构：把散落各处的营业执照、对公账户、电子税务局、法人信息、证照印章等资料，按**「公司主体」+「账套」**的结构化方式收进一个加密金库，逐字段复制、随时调用。

## 核心领域模型：账套（zhàngtào）

在中国财税语境里，**账套**是记账的顶层单位——一个独立核算主体的**完整账务数据集**，包含会计科目、期初余额、凭证、账簿、报表、会计期间、会计准则、纳税人身份、记账币种等。

- **公司主体（Subject）**：营业执照对应的法律实体，以「统一社会信用代码」为唯一标识。承载工商、法人/联系人、证照印章等企业资料。
- **账套（AccountSet）**：一套账；承载账套信息、对公账户、税务、平台系统等财税资料，并**关联一个或多个公司主体**。

**主体 ⟷ 账套 是多对多（M:N）**，这是本插件的核心结构：

- 同一主体可有**多个账套**：不同会计年度、内账/外账、企业会计准则/小企业会计准则、纳税人身份变更（小规模↔一般纳税人）、更换代账机构后新建账套等。
- 同一账套可关联**多个主体**：集团「合并账套 / 共享服务中心」常用一个账套归集多个法人主体；Oracle ERP 的 Ledger（账套）本就允许一个 Ledger 含多个 Company。

调研依据：[知乎·什么是账套](https://zhuanlan.zhihu.com/p/699682002)（Oracle `Ledger` 可含一个或多个公司）、[柠檬云·多账套管理](https://www.ningmengyun.com/zixun/articlePage/78474750906368)（代账公司/集团/个体户多执照等场景）、[金蝶·账套](https://www.kingdee.com/wenda/tag-zhangtaoi/)。

## 安全模型

```
主密码 + 随机盐 --PBKDF2-SHA256(600,000)--> KEK (AES-256-GCM)
随机 DEK (AES-256-GCM, 可导出)  <── KEK 包裹（wrappedDEK，存明处）
金库 JSON  --DEK 加密--> {iv, ct}  → IndexedDB
Passkey(WebAuthn PRF) --HKDF--> passkey-KEK  → 另存一份包裹后的 DEK
```

- **零服务端**：无任何网络上传；OCR 模型按需从 CDN 加载，识别在本机完成，图片不出本地。
- **主密码不落盘**：只保存用主密码派生 KEK 包裹后的 DEK；密码错误时 AES‑GCM 认证失败，无法解密。
- **改主密码不重加密**：只更换包裹 DEK 的钥匙，资料无需整体重加密。
- **每次打开都校验**：关闭面板即清空内存中的 DEK 与明文；无操作 5 分钟自动锁定。
- **可导出加密备份**：导出的是「密文 + 包裹后的 DEK」，换设备后仍需原主密码才能解开。
- **Passkey 说明（重要）**：Passkey 依赖两项浏览器能力，缺一不可：
  1. **安全源**：必须以 **HTTPS** 或 **`http://localhost`** 打开 Harness。`http://127.0.0.1` 等 **IP 源会被 Chromium/Safari 明确拒绝**（WebAuthn 不接受 IP 作为 RP ID）。
  2. **WebAuthn PRF 扩展**：插件用它从 Passkey 派生加密密钥。**macOS 上 Safari 对 PRF 支持不稳定、通常不可用**，请在 macOS 用**最新版 Chrome 或 Edge**（Touch ID），且避免在会被禁用 WebAuthn 的桌面内嵌窗口里使用。
  不支持时会自动回退主密码，主密码始终可用；插件会把「启用 Passkey」置灰并提供「为什么无法启用 Passkey？」诊断说明。
- **在 macOS 上启用 Passkey 的正确方式**：用 Chrome 打开 `http://localhost:<端口>`（把 `127.0.0.1` 换成 `localhost`，端口与 token 不变）→ 进入 OPC Vault →「启用 Passkey」→ Touch ID 验证。

> ⚠️ 安全边界：本工具保护的是「设备外泄/备份泄露」场景下的静态数据。设备若已被植入键盘记录或恶意软件，任何软件都无法保证安全。请使用可信设备与强主密码。

## 安装为 DSH 插件

本仓库根目录即一个 Cordis/DSH bundle（`package.json` 的 `dsh.bundle.patch` 指向 `cordis.patch.yml`）。

方式一：通过插件管理器安装本地包（推荐）——调用 `install_bundle`，`target` 指向本仓库绝对路径。

方式二：手动在 profile 的 `cordis.patch.yml` 追加：

```yaml
- insert:
    - id: opc-vault
      name: '@local/opc-vault'
```

安装后：左侧边栏出现「盾牌钥匙」图标 → 点击进入 **OPC Vault** 面板（概览 / 公司主体 / 账套 / 关系）。

## 使用

1. 首次打开 → 设置主密码（≥8 位），可选启用 Passkey → 创建账套库。
2. 「公司主体」新建主体，填写工商 / 法人 / 证照信息；「账套」新建账套，填写账套信息 / 对公账户 / 税务 / 平台，并在「关联公司主体（多对多）」里勾选所属主体。
3. **批量导入**：点顶部「批量导入」（或概览「快速开始」）→ 一次性粘贴多家公司资料 → 「识别预览」核对 → 「识别并创建」，自动建成多个公司主体 + 多个账套并自动关联。支持两种格式：①逐段「字段：值」，用空行或「名称：」分隔多公司；②从 Excel 直接复制的表格，首行为列名。
4. 任意字段「复制」即可单独复制；图片字段可上传/拖入/粘贴，有图后点「识别」自动抽取公司名、信用代码、法人、注册资本、成立日期。
5. 账套详情点「打开电子税务局」按「所在地区」一键跳转；「关系」视图按主体/账套两个方向查看多对多关联；「导出 / 导入」做加密备份；「锁定」立即上锁。

## 字段一览

- **公司主体 · 工商基础**：公司名称、统一社会信用代码、法定代表人、注册资本、成立日期、营业期限、公司类型、注册地址、经营范围、登记机关、核准日期、纳税人识别号、组织机构代码
- **公司主体 · 法人/联系人**：法人手机/身份证号/邮箱、财务负责人、办税员、公司电话、企业邮箱、注册手机号
- **公司主体 · 证照与印章**：营业执照、电子营业执照、公司电子章、法人身份证正/反面、公章、财务章、法人章、合同章、发票章、银行开户许可证
- **账套 · 账套信息**：账套名称、会计年度、会计准则、纳税人身份、行业类型、记账币种、账套状态、启用日期、代账机构、记账会计、审核会计、主管 + **关联主体（多对多）**
- **账套 · 对公账户**：基本户/一般户 的开户行、账户名称、账号、密码、开户行行号、开户日期
- **账套 · 税务**：电子税务局网址/账号/密码、个税密码、自然人电子税务局、开票软件、社保、公积金、发票抬头
- **账套 · 平台与系统**：电子营业执照小程序、国家企业信用信息公示系统、电子签章平台、企业网银、企业微信/钉钉管理员、域名与备案
- **账套 · 其他**：工商年报提醒、汇算清缴截止、备注；以及任意**自定义字段**
